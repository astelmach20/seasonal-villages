# Publishing Checklist

## Required Files

- `build/libs/seasonal-villages-1.0.0.jar`
- `LICENSE`
- `README.md`
- `CHANGELOG.md`
- `docs/assets/seasonal-villages-icon-source.png`
- `docs/assets/seasonal-villages-gallery.png`

## Modrinth

1. Create a new project named `Seasonal Villages`.
2. Use the summary from `docs/modrinth-description.md`.
3. Upload `seasonal-villages-1.0.0.jar`.
4. Set game version to `1.21.1`.
5. Set loader to `Fabric`.
6. Mark `Fabric API` as a required dependency.
7. Add `docs/assets/seasonal-villages-gallery.png` to the gallery.
8. Publish as release `1.0.0`.

## CurseForge

1. Create a Minecraft mod project named `Seasonal Villages`.
2. Use the description from `docs/curseforge-description.md`.
3. Upload `seasonal-villages-1.0.0.jar`.
4. Set game version to `1.21.1`.
5. Set mod loader to `Fabric`.
6. Mark `Fabric API` as a dependency.
7. Add the gallery image and icon.
8. Submit for moderation.

## Release Notes

Use the `1.0.0` section from `CHANGELOG.md`.
