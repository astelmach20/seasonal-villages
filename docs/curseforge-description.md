# Seasonal Villages

Seasonal Villages gives villages a cozy seasonal rhythm.

When you are near a cluster of villagers, the village reacts to the current season with small buffs, seasonal item sharing, and light outdoor decorations. Use the craftable Village Almanac to check what season the nearby village is experiencing.

## Highlights

- Spring, Summer, Autumn, and Winter cycle automatically.
- Craftable Village Almanac.
- Villager buffs change by season.
- Villagers occasionally share seasonal food or seeds.
- Villages receive capped outdoor decorations.
- Decoration memory persists per world.
- JSON config is generated on first launch.

## Dependencies

- Fabric API is required.
- Built for Minecraft 1.21.1 and Fabric Loader.

## Config

Look for:

```text
config/seasonal-villages.json
```

Server owners can tune season length, village radius, decoration counts, and feature toggles.
