# Seasonal Villages

Seasonal Villages makes Minecraft villages feel a little more alive as the year turns.

Villages now move through Spring, Summer, Autumn, and Winter based on world time. If you are near a real village cluster, villagers receive small seasonal buffs, share occasional seasonal goods, and decorate nearby safe outdoor spaces.

## Features

- Four-season world-time cycle.
- `Village Almanac` item for checking the current village season.
- Nearby-villager detection for active villages.
- Seasonal villager care:
  - Spring: regeneration.
  - Summer: speed.
  - Autumn: saturation.
  - Winter: resistance.
- Seasonal gifts such as seeds, berries, bread, pies, baked potatoes, and cookies.
- Capped decorations such as flowers, lanterns, pumpkins, hay, and snow.
- Persistent per-world decoration memory.
- Configurable season length, village radius, decoration limits, gifts, decorations, and buffs.

## Requirements

- Minecraft 1.21.1
- Fabric Loader
- Fabric API

## Configuration

After first launch, edit:

```text
config/seasonal-villages.json
```

You can change season length, village detection radius, decoration density, and whether gifts/decorations/buffs are enabled.
